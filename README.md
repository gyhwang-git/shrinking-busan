# shrinking-busan

부산광역시 2026년 9월 행정동별 생활인구와 주민등록인구 비율 지도입니다.

## 실행

1. 필요한 패키지: pandas, geopandas, folium, python-dotenv, IPython.
2. 상위 작업 폴더의 .env에 V-WORLD_KEY를 설정합니다.
3. shrinking-busan.ipynb를 열어 셀을 실행합니다.
4. 셀은 data/의 CSV와 GeoJSON을 결합하고 preview_202609.html을 생성합니다.

## 비율 정의

생활인구는 행정동별 24개 시간대에서 주거·직장·방문인구 합계를 구한 뒤 24시간 평균을 계산합니다. 시간대별 값을 더하지 않아 하루 인구를 반복 집계하지 않습니다. 이 값을 2026년 9월 말 주민등록인구로 나눴습니다.

범주는 0.50 미만, 0.50–0.79, 0.80–0.99, 1.00–1.49, 1.50 이상입니다.

## DID 분석 (2015·2024)

손가영(2023)의 인구밀집구역 기준을 적용했습니다. 500m 격자는 0.25㎢이므로 격자 인구 1,000명 이상을 ㎢당 4,000명 이상으로 판정합니다. 이 격자들 가운데 변을 공유하는 연결집단의 총인구가 5,000명 이상이면 해당 집단을 DID로 포함했습니다. 부산 행정동 경계와 교차하는 격자를 분석하고, 읍·면·동 결과는 격자 중심점이 포함되는 2025년 행정동 경계에 집계했습니다.

분석 결과:

- 2015년: 기준 충족 격자 721개, DID 709개 격자·12개 연결집단, DID 격자 인구 합계 3,276,199명
- 2024년: 기준 충족 격자 739개, DID 727개 격자·14개 연결집단, DID 격자 인구 합계 3,094,069명
- 격자 변화: 유지 682개, 탈락 27개, 신규 45개

행정동별 경로는 `data/derived/busan_did_change_by_dong.geojson`에, 연도별 DID와 격자 변화는 `data/derived/`의 GeoJSON에 저장됩니다. 재생성 명령은 `node scripts/build_did_analysis.mjs`, 미리보기 반영은 `node scripts/render_did_preview.mjs`입니다. 결과 요약은 `data/derived/did_summary.json`에서 확인할 수 있습니다.

## 출처

- 생활인구: [공공데이터포털 부산광역시 OpenAPI](https://www.data.go.kr/data/15164444/openapi.do)
- 주민등록인구: [공공데이터포털 행정안전부 CSV](https://www.data.go.kr/data/3033254/fileData.do)
- 행정동 경계: 로컬 프로젝트의 HangJeongDong_ver20250101.geojson에서 부산 206개 동 추출
- 500m 격자 인구: 통계지리정보서비스(SGIS) 2015년·2024년 격자통계
- DID 기준 참고: 손가영(2023), 「인구밀집구역의 공간적 축소에 관한 연구」, 충북대학교 석사학위논문
