# 부산시 인구밀집구역(DID)과 축소 양상 분석

**연구 질문**: 2015–2024년 부산의 인구밀집구역은 어디서 유지·탈락·신규 형성되었으며, 인구감소지역의 정주인구 변화와 생활기능은 어떻게 다른가?

웹페이지는 과제 흐름에 맞춰 연구 질문 → 자료·지표 → 공간 결과 → 비공간 비교 → 결과 해석·한계 순서로 구성했습니다.

## 핵심 쟁점

- DID 격자는 2015년 709개에서 2024년 727개로 18개 늘었지만, DID 격자 인구 합계는 3,276,199명에서 3,094,069명으로 182,130명(약 5.6%) 줄었습니다. **DID 면적·격자 수의 증가가 DID 내부 인구 증가를 뜻하지는 않습니다.**
- 두 시점 사이 유지 격자는 682개, 탈락 격자는 27개, 신규 격자는 45개입니다. 변화는 부산 전체 지도와 행정동·구별 집계로 확인할 수 있습니다.
- 남구·북구·사상구·영도구 비교에서는 정주인구가 모두 감소했습니다. 반면 고용은 영도구만 증가했고, 생활인구/주민등록인구 비율은 사상구와 영도구에서 100%를 넘었습니다. 인구 감소와 지역 기능 변화가 같은 방향으로 움직이지 않는다는 점이 주요 쟁점입니다.

## 자료와 분석 기준

- **DID**: SGIS 500m 인구격자, 2015년·2024년. 셀 인구 1,000명 이상(㎢당 4,000명 이상) 가운데 변을 공유하는 4방향 연결집단의 총인구가 5,000명 이상이면 DID로 분류했습니다. 대각선으로만 닿는 셀은 연결하지 않습니다.
- **공간 집계**: 부산 경계와 교차하는 격자를 분석하고, 행정동 결과는 격자 중심점이 포함되는 2025년 행정동 경계에 연결했습니다.
- **정주인구·고용**: 2021년과 2024년 행정동 자료의 연평균 증감률을 계산했습니다.
- **생활인구 흡인력**: 2024년 행정동 평균 생활인구 ÷ 2024년 말 주민등록인구.
- **생활인구 지속성**: 월별 생활인구 하위 3개월 평균 ÷ 연평균 생활인구. 2024년 자료 기준입니다.
- **광역 이동성**: 구·군 간 주민등록 전입·전출 ÷ 전체 전입·전출. 일상적인 생활 이동량 지표는 아닙니다.
- 지도 산점도는 DID 변화 격자를 점으로 표시합니다. 생활인구 변화는 행정동 단위 자료이므로 같은 행정동 안의 격자에 동일 값이 반복됩니다. 이를 격자별 독립 관측값으로 해석할 수 없습니다.

## 해석과 한계

분석은 DID 경계와 인구 분포의 변화, 구별 기능 지표의 차이를 기술적으로 보여줍니다. 자료별 기준 시점이 서로 다르고(인구격자 2015·2024년, 정주인구·고용 2021·2024년, 생활인구 2023·2024년), 생활인구 지표 일부는 행정동 단위입니다. 따라서 시점 간 변화를 동일 기간의 변화로 간주하거나, DID 변화가 지역 기능 변화의 원인이라고 결론 내릴 수 없습니다. 행정동 경계와 격자 연결 기준에 따라서도 집계 결과가 달라질 수 있습니다.
